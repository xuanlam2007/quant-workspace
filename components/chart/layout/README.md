# Chart layout components

- `navigation/`: chart header/footer, intervals, chart types, and date navigation.
- `symbols/`: symbol search, comparisons, and market data legends.
- `settings/`: chart and study settings, including the shared color picker.
- `panes/`: pane controls, presentation state, and price axis controls.
- `workspace/`: saved layouts, workspace persistence, and layout actions.

Keep feature-specific icons beside their controls. Shared chart configuration stays in `../config`, and reusable interaction hooks stay in `../ui`.
